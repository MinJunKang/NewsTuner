📻 뉴스 튜너 — 영어 뉴스 읽기 앱 설치 안내

민준이가 만든 앱이에요. 영어 뉴스를 수준에 맞게 읽고,
모르는 단어를 손가락으로 누르면 바로 뜻이 나옵니다.

━━━━━━━━━━━━━━━━━━━━━
① 설치하기 (한 번만)
━━━━━━━━━━━━━━━━━━━━━

1. 크롬(Chrome)을 열고 아래 주소로 들어가세요
   👉 https://minjunkang.github.io/NewsTuner/

2. 오른쪽 위 점 세 개(⋮)를 누르고
   "앱 설치" 또는 "홈 화면에 추가"를 누르세요

3. 홈 화면에 라디오 모양 아이콘이 생깁니다.
   다음부터는 이 아이콘만 누르면 돼요.

━━━━━━━━━━━━━━━━━━━━━
② 처음 한 번 설정 (두 칸만 입력)
━━━━━━━━━━━━━━━━━━━━━

앱을 열면 "설정" 화면이 먼저 나옵니다.
아래 두 칸에 그대로 복사해서 붙여넣으세요.

▸ 프록시 주소:
https://news-tuner.vercel.app/api

▸ 프록시 토큰:
(여기에 토큰 붙여넣고 보내주세요)

두 칸을 채우면 "준비됐습니다"라고 나옵니다.
GEMINI API KEY 칸은 비워 두시면 됩니다.

━━━━━━━━━━━━━━━━━━━━━
③ 사용법
━━━━━━━━━━━━━━━━━━━━━

1. 아래쪽 "읽기"를 누르세요
2. 분야를 고르세요 (News, Health, Culture 등)
3. 난이도는 "쉽게"를 추천해요
4. "주파수 맞추기"를 누르면
   30초~1분 뒤 오늘의 기사가 도착합니다

📖 읽다가 모르는 단어가 나오면
   → 그 단어를 손가락으로 톡 누르세요. 뜻이 바로 떠요.

💬 기사가 궁금하면 아래 "질의응답"에서
   한국어로 물어봐도 됩니다.
   (예: "이 기사 핵심을 한국어로 3줄 정리해줘")

━━━━━━━━━━━━━━━━━━━━━
④ 뭔가 안 될 때
━━━━━━━━━━━━━━━━━━━━━

설정 화면 → "오류 기록" → [바로 전송] 버튼을
한 번 눌러 주세요. 그러면 민준이한테 자동으로
알려져서 고쳐 드립니다.

궁금한 건 언제든 전화 주세요 📞
